Exclusão de Dados do Usuário

Sofia Alho & Temperos RJ · Assistente virtual Sofia no WhatsApp · Última atualização: 24/10/2026

Você pode pedir a exclusão dos dados pessoais que a Sofia Alho & Temperos RJ guarda sobre você a partir das conversas com a assistente virtual Sofia no WhatsApp.

Como pedir a exclusão

Use uma destas opções:

  1. Pelo WhatsApp: envie a mensagem
    EXCLUIR MEUS DADOS
    para o mesmo número de WhatsApp com que você conversou.
  2. Por e-mail: escreva para composer@projectauraos.com com o assunto "EXCLUIR MEUS DADOS". Informe o número de telefone usado no WhatsApp.

O que acontece depois

  • Vamos confirmar que o pedido é seu, pelo número de telefone de onde ele veio.
  • Os seus dados (nome, telefone, histórico de mensagens e dados de atendimento) serão excluídos ou anonimizados em até 30 dias.
  • Você vai receber uma confirmação pelo WhatsApp ou por e-mail quando a exclusão for concluída.

Exceções

Alguns dados podem ser guardados pelo tempo exigido em lei, como documentos fiscais de compras já feitas, conforme o art. 16 da LGPD. Esses dados ficam guardados apenas para essa finalidade.

Saiba mais na nossa Política de Privacidade.
